Реализовано:
* Service A — раз в минуту получает текущие данные о погоде в г. Казани из открытого API.
* Service A — отправляет полученные данные о погоде в Kafka в топик weather.
* Service B — получает данные из Kafka и передаёт их в Service C через gRPC-метод SetWeather.
* Service C — реализует gRPC-метод SetWeather для приёма данных о погоде.
* Service C — сохраняет полученные данные в PostgreSQL с использованием Entity Framework Core.
* Service C — предоставляет REST API для получения последних 10 значений погоды с временем их получения.
* Service C — автоматически удаляет записи старше 10 часов: очистка выполняется при запуске сервиса и повторяется каждые 10 часов.
* Для взаимодействия с БД реализован отдельный слой хранилища (IWeatherStorage), отделяющий работу с данными от бизнес-логики.
* Конфигурация и регистрация сервисов вынесены в методы расширения для уменьшения объёма Program.cs.
* Для Service C добавлен Swagger для тестирования REST API.
* Для хранения данных PostgreSQL добавлен в docker-compose.yml с сохранением данных через Docker volume.
